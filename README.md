# Generador de Contraseñas en Python

Este proyecto es un generador de contraseñas seguras escrito en Python.  
Permite elegir la longitud de la contraseña y si deseas incluir mayúsculas, números y símbolos.

## Características
- Contraseñas personalizables
- Uso de módulos estándar de Python
- Fácil de ejecutar desde la terminal

## Cómo usarlo
1. Asegúrate de tener Python 3 instalado.
2. Ejecuta el archivo con:

python password_generator.py

3. Responde a las preguntas del programa para generar tu contraseña.

## Tecnologías utilizadas
- Python 3
- random
- string
